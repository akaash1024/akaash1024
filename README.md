## 🚀 Featured Projects

### 🚌 Multi-Tenant Bus Booking Platform
Production backend currently used by a real bus booking business — replaced manual, notebook-based record keeping.
- Multi-tenant architecture with dynamic tenant resolution; each client location runs on an isolated PostgreSQL database
- **Stack:** NestJS, PostgreSQL
- **Status:** Live, in active use by real customers

### 💼 HireDD — Job Portal Platform
Full-stack job portal with role-based auth for recruiters and job seekers.
- JWT authentication with secure cookie-based sessions, file uploads
- Search, filtering, and pagination for efficient job discovery
- Building AI-powered matching features + admin dashboard
- **Stack:** React.js, Node.js, Express.js, MongoDB, Redux Toolkit, Cloudinary

### 🔐 Library Management System
RESTful API supporting complete library operations.
- 10+ endpoints covering catalog, borrowing, and user management
- Role-based access control with JWT + bcrypt
- **Stack:** Node.js, Express.js, MongoDB, Mongoose, JWT
